How this run works

Questions rotate through difficulty and sections. A repository discovery case follows every eight existing questions, cycling Games, Hourglass and DSG. Each round attempt has 15 minutes, including tools and interrupted-resume time. Timeouts earn zero. Later rounds repeat the whole bank: wrong, unfinished, correct—slowest first. The run also stops at 60 active minutes and plays a completion chime.

What gets scored?

Games use one exact answer across six assertions. Incorrect answers and execution errors are reported separately. Questions not reached within the hour earn no points.
